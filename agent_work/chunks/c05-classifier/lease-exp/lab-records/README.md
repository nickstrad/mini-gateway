# Lease-lab records

These are the builder notes and review records of the lease experiment, copied byte for byte
from the local branch `exp/lease-lab` (tip `5ffc7a3`) by the port of
`agent_work/chunks/lease-lab-port/` (the copy list with blob hashes is in that folder's
`NOTES.md`). E0's `NOTES.md` is here as `NOTES-E0.md`; every other file keeps its name.

- `NOTES-E0.md` to `NOTES-E6.md`: the builder notes of steps E0 to E6. `NOTES-E0.md` section
  4 describes the schema (`mgcalib-calibration/1`) of `../calibration.json`.
- `REVIEW-1.md`, `REVIEW-2.md`, `REVIEW-E1-1.md` to `REVIEW-E6-2.md`: the review records.

The code, scripts and run directories these files name (`internal/lab/`, `cmd/mglease/`,
`cmd/mgcalib/`, `scripts/lease-exp.sh`, `scripts/lease-calib.sh`, `runs/r0-*`, `e4-evidence/`,
`e5-smoke/`, `e5-rehearsal/`, `manifests/`) were not kept, so links and paths to them do not
resolve. The report SQL and `lease-report.sh` are kept in `../report-sql/`, and the isolation
oracle SQL in `../e7/isolation/e4.sql`. The branch was deleted after this port; the keep and
drop verdicts are in `agent_work/chunks/lease-lab-port/EVALUATION.md`.
