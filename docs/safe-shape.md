# The safe shape

Generated by `scripts/gen-docs.sh` from `internal/pgwire/share.go`. Do not edit by hand: a test fails when this file differs from the code.

A `Query` text fits the safe shape when all of the rules below hold. Only then is it `SafeRead` (a read for the error contract: `08006` rather than `08007` after a lost connection) and, outside a transaction and not rejected, `Shareable` (shared by `coalesce: auto`). The check reads the raw bytes; it uses neither the lexer nor the reject classifier. Anything it does not list does not fit.

## Rules

1. The text is 1 to 4096 bytes long.
2. Every byte is an ASCII letter, an ASCII digit, or one of `_` `,` `*` `=` `<` `>` `(` `)` `'` the space (0x20). No tab, line break, dot, semicolon, backslash, dollar sign, double quote, minus, slash, colon, plus, percent or non-ASCII byte.
3. Toggling in and out of a string at every `'` (so `''` toggles twice), the text ends outside a string.
4. The byte before every opening `'` is not a letter, a digit or `_` (no `E'...'`, `B'...'`, `X'...'`, `N'...'`).
5. No string, lower-cased, contains `now`, `today`, `tomorrow`, `yesterday` (Postgres's relative-time input words; a substring match).
6. Outside strings, the first word is `select` (any case) and nothing but spaces comes before it. A word is a maximal run of letters, digits and `_`.
7. Outside strings, no word is on the stop list.
8. Outside strings, every word followed (after optional spaces) by `(` is on the parenthesis-keyword list or on the share allow-list.

Words are compared ASCII case-insensitively.

## Stop list

`into`, `for`, `with`, `tablesample`, `insert`, `update`, `delete`, `merge`, `truncate`, `create`, `alter`, `drop`, `grant`, `revoke`, `call`, `do`, `copy`, `lock`, `set`, `reset`, `show`, `prepare`, `execute`, `deallocate`, `listen`, `notify`, `unlisten`, `declare`, `fetch`, `move`, `close`, `begin`, `start`, `commit`, `rollback`, `abort`, `savepoint`, `release`, `discard`, `load`, `vacuum`, `analyze`, `explain`, `refresh`, `reindex`, `cluster`, `checkpoint`, `comment`, `import`, `security`, `values`, `table`, `current_date`, `current_time`, `current_timestamp`, `localtime`, `localtimestamp`, `current_role`, `current_user`, `session_user`, `system_user`, `user`, `current_catalog`, `current_schema`

## Parenthesis keywords

Words that may precede `(` without being a function call. Each is a reserved or column-name keyword in PostgreSQL 17, which no unqualified function call can use as its name.

`select`, `from`, `where`, `and`, `or`, `not`, `in`, `on`, `exists`, `any`, `all`, `some`, `when`, `then`, `else`, `having`, `union`, `intersect`, `except`, `as`, `limit`, `offset`, `distinct`, `between`, `case`

## Share allow-list

Functions with no side effect and no per-call or per-session result.

`abs`, `ascii`, `avg`, `bit_and`, `bit_length`, `bit_or`, `bool_and`, `bool_or`, `btrim`, `cbrt`, `ceil`, `ceiling`, `char_length`, `character_length`, `chr`, `coalesce`, `concat`, `concat_ws`, `count`, `degrees`, `div`, `every`, `exp`, `floor`, `gcd`, `greatest`, `initcap`, `lcm`, `least`, `left`, `length`, `ln`, `log`, `log10`, `lower`, `lpad`, `ltrim`, `max`, `md5`, `min`, `mod`, `nullif`, `octet_length`, `pi`, `pow`, `power`, `radians`, `repeat`, `replace`, `reverse`, `right`, `round`, `rpad`, `rtrim`, `sign`, `split_part`, `sqrt`, `starts_with`, `string_agg`, `strpos`, `substr`, `sum`, `to_hex`, `translate`, `trunc`, `upper`

## Hint

A text that begins with the exact bytes `/* mg:share */` is reported as `Hinted`. The hint never makes a text `SafeRead` or `Shareable`; in `hinted` mode the coalescer shares on the mark alone.
