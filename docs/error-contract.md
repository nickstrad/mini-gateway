# Error contract

Generated by `scripts/gen-docs.sh` from `internal/pgwire/errors.go` (the table `ErrorRows`). Do not edit by hand: a test fails when this file differs from the code.

Every reply the proxy makes itself is an `ErrorResponse` with the severity, SQLSTATE and message below and a detail line `mini-gateway error row: <row id>`, followed by the end marker the row names. `ERROR` rows end with `ReadyForQuery` carrying the status byte the client believes (`I` outside a transaction; inside one, the current status). `FATAL` rows have no end marker and the client connection is closed. The extended-protocol row discards messages until `Sync` and then sends `ReadyForQuery`. Each proxy-made reply is counted under its counter key.
