# Capacity table

Generated by `scripts/gen-docs.sh` from `internal/proxy/contracts.go` and `internal/shell/contracts.go`. Do not edit by hand: a test fails when this file differs from the code.

One row per bounded thing in the walking skeleton (chunk 6), with its default. Config validation also checks that the gates in front of the connections are consistent: the queue holds at most one request per client (`queue.capacity` ≤ `limits.max_clients`), the clients in startup are at most the clients (`limits.max_startup` ≤ `limits.max_clients`), and the pool fits the fleet budget (`pool.connections` ≤ `fleet.backend_connections` / `fleet.instances`). A cap with a config key that is zero or omitted in the config file takes its default (the number shown); a negative cap is refused with an error naming its key.
