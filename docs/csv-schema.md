# CSV flush schema, version 1

GENERATED by `scripts/gen-docs.sh` from `internal/obs/catalog`; do not edit by hand. `internal/obs/catalog` holds a test that fails when this file differs from the code.

## Run directories

One run is one directory `<obs.csv.dir>/<run_id>/` with three files. Simulator runs use the run id `<scenario>/<seed>/<arm>`, so a root holds `<root>/<scenario>/<seed>/<arm>/`. `metrics.csv` and `histograms.csv` get rows appended at every flush, sorted by (`flush_seq`, `instance`, `component`, `metric`, labels); `run.csv` is written last, at close. A directory without `run.csv` did not finish.
