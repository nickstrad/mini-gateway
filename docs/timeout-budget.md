# Timeout budget

Generated by `scripts/gen-docs.sh` from `internal/proxy/contracts.go` and `internal/proxy/config.go`. Do not edit by hand: a test fails when this file differs from the code.

Every wait the walking skeleton (chunk 6) has, with its initial value. Every value is initial and is tuned by a named experiment later (PLAN.md section 9.2). Config validation refuses a file whose waits do not nest (the second table).

One rule holds for every deadline: time passes before the event. When an event arrives at time T, `Engine.Step` first fires every timer due at or before T, then processes the event, so a reply, a byte or a free connection that arrives at the very instant of its deadline is late and the deadline's outcome applies.
