# Fault × path matrix

Generated by `scripts/gen-docs.sh` from `internal/proxy/matrix.go` (`FaultMatrixRows`). Do not edit by hand: a test fails when this file differs from the code.

One row per fault and place in the conversation: the error-contract row the client gets (`docs/error-contract.md`), the deadline that bounds its wait, whether the request may have reached the database, and whether the proxy itself retries it. The proxy retries only a failure where nothing reached the database for certain, outside a transaction; such a failure is answered with `lost-after-read` when the policy declines. Tests are Go test names or simulator scenario names (`test/e2e`).
